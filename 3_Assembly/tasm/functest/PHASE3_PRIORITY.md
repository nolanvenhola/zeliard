## Authoring loop (per PLAN §4.2)

1. Pick the top unfinished row.  Note its entry_addr and IDA hint (if any).
2. Read the proc body in the chunk's .asm — eyeball the prologue: does it `cmp [SI+N], const`?  Branch on CF from a stubbed callee?  Touch a fixed DS offset?
3. Stamp a test:
   ```
   python new.py <chunk> 0x<addr> --name <short> --hyp "<IDA-hint or static-derived guess>"
   ```
4. Edit the stamped test — typically 2–4 probes covering distinct branches.  Use `make_player_record` and `stub_video_drivers` from fixtures.py.
5. Run it: `python run.py --filter test_<chunk>_<short>.py`.
6. Commit a `VERDICT: PASS|REFUTED|...` line; update `INDEX.md` with the test row.
7. If the proc has an IDA hint and the verdict CONFIRMS it, add a static rename in the chunk's `.asm` (the proc declaration + every `call`-site).  Re-verify bit-perfect.

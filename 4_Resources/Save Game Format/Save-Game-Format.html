This page contains notes for the game Zeliard (DOS).

This page covers all research collected on the data used to generate save files. All data presented is listed as hex values. The same data is arranged and used in all versions of the game. You can find them at:

  • PC-88 & Sharp X1: User Disk, starts at 0xB40
  • DOS: Save files, starts at 0x00

The points of data listed below are for the DOS version (And uses their English names). For the other versions, just shift up the values. Example: 0x00 -> 0xB40, 0x80 -> 0xBC0, etc.

This data is mainly for game progression, what stuff you have collected, etc. Many of the in-game details check this area to see if you have collected certain items, rather than what is in your inventory section (Including the crazy guard who blocks the path to the 3rd dunegon boss, Pollo.)

CHARACTER DATA

All data related to your character: Stats, inventory, sage visits and what you can purchase at stores.

80 - Physical location on the map where you start in a town.
- The maximum values will be listed. The Tile Max refers to maximum number of tiles used in the width of the map screen. The Display Max is as high as you should input the number. If the number entered in is higher than what is listed in the Display Max, you may start outside the map boundaries and be unable to do anything in the game.
- All town building points are based on the Tile Max values. Entering them in as they are will place the door entrance along the far left side of the screen.
- If you choose to re-locate your character to another town, 00 is the safest value to use.

NOTES:

  • The LIFE bar displays 1 pixel for every 4 HP you have, rounded down. Some sites misreport this information as 8 HP because they are using a lower resolution to play the game, like CGA, TGA or MCGA, which reduces the resolution to 320 x 200. The native resolution for this game is 640 x 200 (stretched to 640 x 400).
(Source: Kuro-chan)
